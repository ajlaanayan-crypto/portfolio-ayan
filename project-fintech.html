Fintech Trading Analysis

A next-gen stock market terminal that merges real-time quotes with interactive 3D visualizations and Gemini-powered sentiment insights.

The Challenge

Aggregating live quotes and high-density news from external APIs without hitting strict rate limits. Ensuring a unified data client structure between a decoupled Next.js frontend and Express backend. Creating responsive financial charts and embedding an AI assistant for quick market queries.

Role

Full Stack & AI Integrator

Implementation Details

We built a clean, decoupled data pipeline where the client (`frontend/lib/api.ts`) communicates with our Express server proxy. The server coordinates price queries, historical arrays, and market news feeds from Yahoo Finance. To optimize performance and bypass Google Gemini API rate blocks, we engineered an in-memory caching engine that saves quote details and sentiment values temporarily.

Using Google Gemini 1.5 Flash, the engine scans headlines to extract market sentiment flags (Bullish/Bearish). We also integrated a secure post route (`/ai/chat`) enabling interactive dialogs with an AI chatbot that references real-time market activity. Glassmorphism cards float over a mouse-reactive 3D mesh background utilizing Three.js and Vanta.js, complete with Chart.js visualization tools.
