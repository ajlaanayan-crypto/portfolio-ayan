PDF Vibe Watermarker

A modern, local-first web application built with Python & Streamlit to add professional image watermarks to PDFs, merge files, and reorder pages locally.

The Challenge

Online PDF watermarkers are typically paid subscription services or present privacy concerns by uploading personal college assignments to public cloud servers. The goal was to build a local-running, privacy-first web utility to customize opacity, scale, and positioning of watermarks with instant previews, plus document merging and page reordering, completed in under 1 week.

Role

Sole Python Developer

code View on GitHub

Implementation Details

We leveraged PyMuPDF (`fitz`) for low-level high-performance PDF manipulation, handling page extraction and watermark stamp overlays natively on the client device. Pillow handles image transformations including rotation matrices, transparency scaling, and placement coordinates. An in-memory buffer converts output PDF slices instantly, allowing live layout previews on the Streamlit dashboard.

Streamlit's standard theme restrictions were bypassed by injecting structured HTML/CSS stylesheets directly into `st.markdown`, providing a sleek, glassmorphic layout. Additional features include a multi-format file merger (`pdf_tools.py`) that converts raw JPEG/PNG images and appends them to PDFs on-the-fly, alongside custom page index selector sequences to reorder files with clean user interactions.
